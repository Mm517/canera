# بُنّ — رحلة القهوة ثلاثية الأبعاد (GSAP + Lenis + Three.js)

## التشغيل
فك الضغط وافتح `index.html` في Chrome/Edge/Firefox/Safari (مفيش تثبيت ولا إنترنت). أو: `python -m http.server` وافتح localhost:8000.

## الرحلة (بتتحرّك مع السكرول)
علبة الغلاف ← زراعة (شتلة ← نمو ← زهور ← كرز أخضر ← أحمر) ← قطف في السلّة ← معالجة وتجفيف ← تحميص (أسطوانة + عدّاد حرارة) ← طحن/استخلاص/تجميد وتجفيف ← تعبئة البرطمان وقفله ← الكوباية ← التشكيلة ← طريقتك.

## الملفات
- `js/config.js` — كل النصوص، اسم البراند `BRAND`، التشكيلة `P`، طرق التحضير `K`، كلام كل مرحلة `CH`.
- `js/core.js` — الرندر والإضاءة + مجسّم حبّة البن/الكرزة/الورقة.
- `js/jar.js` — العلبة (زجاج + حبيبات + غطا + ليبل بيتولّد بالكود).
- `js/stage_*.js` — مشاهد المراحل. `js/main.js` — GSAP/ScrollTrigger/Lenis.
- `vendor/` — three r128, gsap 3.12.5, ScrollTrigger, lenis 1.1.20 (محلية).

## تخصيص البراند
غيّر `BRAND.name` أو حط لوجوك الرسمي: `BRAND.logo='assets/logo.png'`. ألوان الليبل والغطا في `P`.

## الإضافات
- `js/enhance.js` + `enhance.css`: مزارعين بيزرعوا الشتلة، مطبخ بيت وعلبة تفاعلية في الغلاف، انتقالات سينمائية.
- `js/variants.js` + `variants.css`: التشكيلة كصفحات بتطلع مع السكرول (الاسم بيتلوّن لتحت والكلام بينوّر كلمة كلمة).
- `js/v3.js` + `v3.css`: أرض وشجرة أطبع، كوباية بلاتيه آرت، طبقات القهوة بالأسهم، وكروت "في أي مكان".
- `js/v4.js`: عمّال ومشاهد المعالجة والتحميص والاستخلاص (عدّاد حرارة، شوالات، أشعة شمس، فنّي معمل).

## الإضافات الجديدة (v5–v9)
- `js/people.js`: شخصيات بشرية (هيكل عظمي + IK لليدين): فلاحين، عمّال، متسوقين، كاشير… بأوضاع (حفر/زرع/ري/قطف/جمع/مشي/جلوس/شرب/كتابة/سواقة/قراءة).
- `js/v6.js` + `v6.css`: الغلاف — العلبة قدّامك وبتتفتح وتتفكك مع السكرول (غطا، فويل، ليبل، حبيبات، زجاج) مع شروحات تتتبّع الأجزاء.
- `js/v7.js`: التجفيف — أسرّة تجفيف أفريقية حقيقية (أرجل، شبك، شبكة تظليل)، أشعة شمس، شوالات، عمّال بيقلّبوا.
- `js/v8.js`: «العلبة معاك في كل حتة» — مطبخ/شغل/عربية/رحلة/مذاكرة كمشاهد 3D.
- `js/v9.js`: سوبر ماركت — مشي بمنظور شخص أول: باب بينفتح ← ممر رفوف ← ركن بُنّ ← العلبة تتحط في العربية ← كاشير.

## الطبقة الاحترافية (pro) — آخر تحديث
- `pro.css` + `js/pro.js`: بيتحمّلوا آخر حاجة. لودر بعدّاد ٠–١٠٠ وستارة بتتفتح، قائمة كاملة بالشاشة، كيرسر مخصّص (للماوس بس)، أزرار مغناطيسية، مؤشّر الفصل الحالي في النافبار، «حكايتنا» بنص بيتنوّر كلمة كلمة وماركي بيتأثّر بسرعة السكرول وعدّادات، وفوتر بعلامة عملاقة.
- **الأداء:**
  - سقف الدقة ١.٥ (وبينزل تلقائي ١.٢٥ ← ١ ← ٠.٨٥ لو الجهاز بيهنّج).
  - اتشال كل `backdrop-filter` والـ grain المتحرك (كانوا بيقلّوا الفريمات فوق الـ WebGL).
  - `PRO.warm()` بيرسم كل مشهد مرّة ورا اللودر، فالـ shaders والتكسشرات بتتجهّز قبل ما توصلها (مفيش نهتّة وقت الانتقال).
  - شريط التقدّم بـ transform بدل width، وعناصر الـ HUD متخزّنة بدل ما تتدوّر عليها كل فريم.
  - الأنيميشنز اللي في الصفحات المخفية متوقّفة.
- تعديل النصوص والألوان لسه من `config.js` و`pro.css` (متغيّرات `:root`).

## أقسام إضافية (sections)
- `sections.css` + `js/sections.js`: ليه بُنّ؟ (بينتو متحرّك) · ٣ خطوات (كوباية بتتملي مع السكرول) · على مزاجك (بيقترح تشكيلة وطريقة من `P` و`K`) · مقارنة · أسئلة وأجوبة · اشتراك · حبوب باراللاكس · زرار للأعلى.
- فورم الاشتراك شكلًا بس: حط رابط خدمة الفورم في `FORM_ENDPOINT` أول `js/sections.js`، وإلا الإيميل مابيتبعتش لأي مكان.
- النصوص في `index.html` (داخل `#more` و`#after`).
